# Wi-Fi ルーター・IoT 機器を守る

ルーターは家全体の入口です。ここが破られると全端末が危険にさらされ、ネットワークカメラなどの
IoT 機器は乗っ取り・盗撮・盗聴の標的になりやすいので、優先的に固めます。

## 1. ルーター本体
- [ ] **管理画面のログインパスワードを初期値から変更**（"admin/admin" のままにしない）。長く固有のものに。
- [ ] **ファームウェアを最新に更新**し、可能なら自動更新をON。サポート切れ機種は買い替えを検討。
- [ ] **Wi-Fi 暗号化は WPA3**（対応していなければ WPA2-AES/PSK）。WEP・TKIP は使わない。
- [ ] **Wi-Fi パスワードを強固に**（推測されにくい長いパスフレーズ）。流出時は変更。
- [ ] **WPS を無効化**（PIN 総当たりの弱点になりやすい）。
- [ ] **インターネット側からのリモート管理を無効化**（Remote Management / WAN 側管理画面）。
- [ ] **UPnP は使わないなら無効化**（勝手なポート開放を防ぐ）。必要な機器だけ手動でポート設定。
- [ ] **SSID をステルスにしすぎない**（効果は限定的）。それより上記の暗号化・パスワードが重要。
- [ ] 不要なら **DMZ / ポート開放を全て閉じる**。

## 2. ネットワークの分離
- [ ] **ゲスト用 SSID を作り、IoT 機器（カメラ・スマート家電・テレビ等）はそちらに隔離**。
  - 万一 IoT が乗っ取られても、PC やスマホのある主ネットワークへ被害が広がりにくい。
  - 「ゲストネットワーク内の端末同士の通信を禁止」する設定があればON。
- [ ] 来客用 Wi-Fi も主ネットワークと分ける。

## 3. つながっている端末の確認（侵入・タダ乗りの発見）
- [ ] ルーター管理画面の **接続デバイス一覧** を定期的に確認し、見覚えのない端末がいないか点検。
- [ ] 自動でやるなら HomeWatch のネットワークスキャナ（→ `../network/deploy.md`）。
  - 既知の端末リストと突き合わせ、**新しい MAC アドレスが現れたら通知**します。

## 4. IoT 機器（特にネットワークカメラ）
- [ ] **初期パスワードを必ず変更**。多くの乗っ取りは初期/弱パスワードが原因。
- [ ] **ファームウェアを更新**。サポートの無い格安機器は使わない。
- [ ] **使わないクラウド連携・リモートアクセス・P2P 機能は無効化**。
- [ ] カメラは **設置場所と画角に注意**（プライバシー空間を映さない）。録画の保存先・共有範囲も確認。
- [ ] スマートスピーカー等は **マイクのミュート機能**を活用し、不要時はオフ。

## 5. もう一歩
- [ ] ルーターの **DNS を信頼できるもの**に（プロバイダ標準／公開DNS）。勝手に変更されていないか点検。
- [ ] ログ機能があれば有効化し、ときどき不審なアクセスを確認。
- [ ] 重要機器には **固定IP＋MACで管理**しておくと、HomeWatch の既知端末リスト運用が楽になります。
