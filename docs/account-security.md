# アカウント乗っ取りを防ぐ・すぐ気づく

PC やスマホ本体だけでなく、**Google / Apple / Microsoft / SNS / 銀行などのアカウント**が乗っ取られると、
端末が無事でも被害が出ます。乗っ取りに「すぐ気づく」仕組みもここで作ります。

## 1. 乗っ取りに即気づく（検知）
- [ ] **新規サインイン通知をON**：知らない端末/場所からのログインをメールやプッシュで通知。
  - Google: アカウント > セキュリティ > 最近のセキュリティ関連のアクティビティ／通知設定。
  - Apple: 信頼できないデバイスからのサインイン時に通知が届く（2ファクタ認証が前提）。
  - Microsoft: アカウント > セキュリティ > サインインアクティビティ／アラート。
- [ ] **ログイン履歴・端末一覧を定期確認**：
  - Google「お使いのデバイス」、Apple ID のデバイス一覧、Microsoft の「最近のアクティビティ」。
  - 見覚えのない端末があれば **サインアウト＋パスワード変更＋2段階認証見直し**。

## 2. 乗っ取りを防ぐ
- [ ] **すべての重要アカウントで2段階認証（2FA）を有効化**。
  - できれば **認証アプリ（TOTP）やパスキー/セキュリティキー** を使う（SMS は最低限の手段）。
- [ ] **パスワードは固有・長く**。使い回しをやめる。**パスワードマネージャー**の利用を推奨。
- [ ] **パスキー（Passkey）対応サービスはパスキーに移行**。フィッシングに強い。
- [ ] **連携している外部アプリ（OAuth）の棚卸し**：
  - Google/Apple/Microsoft/SNS の「アカウントにアクセスできるアプリ」を開き、**使っていない・心当たりのない連携を解除**。
  - 乗っ取りの常套手段。定期的に見直す。
- [ ] **回復用の電話番号・メールを最新かつ安全に**保つ（ここを乗っ取られると本体も奪われる）。

## 3. 漏洩していないか確認する
このリポジトリに、パスワードの漏洩を安全に確認するツールが入っています。

```bash
python3 tools/check-pwned-password.py
# プロンプトにパスワードを入力（画面には表示されません）
```
- 仕組み：Have I Been Pwned の **Pwned Passwords range API（k-匿名方式）** を使用。
  送信するのは SHA-1 ハッシュ40桁のうち **先頭5桁だけ**で、パスワードそのものや完全なハッシュは送りません。
  突き合わせは手元で行うため、入力したパスワードが外部に漏れることはありません。
- 結果が「漏洩あり」なら、そのパスワードは即変更し、使い回している他サービスも変更してください。
- [ ] **メールアドレスの漏洩確認**：haveibeenpwned.com で自分のメールが過去の侵害に含まれていないか確認し、
  該当サービスのパスワードを変更・2FA設定。

## 4. 家族のアカウント（合意の上で）
- [ ] 家族それぞれが上記「即気づく」「防ぐ」を **自分のアカウントで** 設定。
- [ ] 未成年の子は **ファミリー共有 / ファミリーリンク**（公式）で保護者がアカウントを管理 → `smartphone-hardening.md`。
- [ ] 共有アカウント（動画配信など）も2FA・固有パスワードにし、連携アプリを点検。
