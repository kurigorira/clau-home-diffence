# Windows PC を守る

侵入・乗っ取り・盗聴を防ぐための設定と、HomeWatch 監視ツールの導入手順です。
各項目にチェックを付けながら進めてください。

## 1. 基本の守り
- [ ] **Windows Update を自動更新に**（設定 > Windows Update）。月例更新は最重要のセキュリティ対策。
- [ ] **Microsoft Defender ウイルス対策が有効**（設定 > プライバシーとセキュリティ > Windows セキュリティ）。
  - リアルタイム保護・クラウド配信保護・改ざん防止（Tamper Protection）をON。
- [ ] **Windows ファイアウォールが有効**（ドメイン/プライベート/パブリックすべて）。
- [ ] **標準ユーザーアカウントで日常利用**。管理者アカウントは普段使わない。
  - マルウェアが動いても権限が限られ、被害を抑えられる。
- [ ] **UAC（ユーザーアカウント制御）を既定以上に**。設定変更時に確認が出る状態を保つ。

## 2. ログイン・認証を固める
- [ ] **強固なサインインパスワード**＋可能なら **Windows Hello（顔/指紋/PIN）**。
- [ ] **画面ロックの自動化**（設定 > アカウント > サインイン オプション > 「しばらく操作しない場合」）。
- [ ] **Microsoft アカウントの2段階認証**を有効化（→ `account-security.md`）。
- [ ] **ロック画面に通知の中身を出さない**（のぞき見対策）。

## 3. リモート侵入の入口をふさぐ
- [ ] **リモートデスクトップ（RDP）を使っていないなら無効**（設定 > システム > リモートデスクトップ＝オフ）。
  - 使う場合はネットワークレベル認証(NLA)必須＋強固なパスワード＋できればVPN経由に限定。
- [ ] **不要なファイル共有を無効化**（共有フォルダの棚卸し。Everyone 共有は特に注意）。
- [ ] **不要な常駐サービス/アプリを停止**。心当たりのないスタートアップ項目を点検（タスクマネージャー > スタートアップ）。

## 4. データ保護
- [ ] **BitLocker でディスク暗号化**（盗難・紛失時に中身を守る）。回復キーは安全な場所に保管。
- [ ] **重要データは別媒体/クラウドにバックアップ**（ランサムウェア対策にもなる）。

## 5. 盗聴・盗撮対策
- [ ] **マイク/カメラのアプリ権限を点検**（設定 > プライバシーとセキュリティ > カメラ / マイク）。
  使っていないアプリのアクセスはオフ。
- [ ] HomeWatch の `Test-MicCameraAccess` が、**許可リスト外のアプリがマイク/カメラを使ったら通知**します（後述）。
- [ ] 物理カメラカバーの併用も有効。

## 6. HomeWatch 監視ツールの導入（すぐ気づくための仕込み）
追加ソフト不要。Windows 標準の機能だけで動きます。**管理者 PowerShell** で実行してください。

```powershell
# リポジトリの windows フォルダに移動して
powershell -ExecutionPolicy Bypass -File .\Install-HomeWatch.ps1
```
- 「いま正常な状態」をベースラインとして記録し、タスクスケジューラに15分ごとのスキャンを登録します。
- 検知すると **画面通知** ＋ `%ProgramData%\HomeWatch\homewatch-alerts.log` に記録します。
- 検知内容・アラートの読み方・誤検知時の対処は **`how-it-works.md`** を参照。

設定の調整（失敗ログオンの閾値、許可ポート、許可アプリ等）は `windows/config/homewatch.config.psd1`。
新しいアプリ等を入れて自動起動が正規に増えた後は、`Update-Baseline.ps1` でベースラインを更新します。

```powershell
powershell -ExecutionPolicy Bypass -File .\Update-Baseline.ps1   # 正規の変更を取り込む
powershell -ExecutionPolicy Bypass -File .\Uninstall-HomeWatch.ps1 -RemoveData  # 取り外し
```

## 7. 侵入された“かも”のサイン
- 見覚えのない管理者アカウント、勝手に変わる設定、急な動作の重さ・発熱・通信量増
- セキュリティソフトが無効化されている
- これらは HomeWatch のアラート（`account` / `persistence` カテゴリ）でも拾えます。
  心当たりが無ければ、ネットから切り離して調査・対処してください（→ `how-it-works.md`）。
